### 1. 医学的判断の代わりにはなりません

- プロンプトを使って生成AIが出力した内容は、診断・治療方針・処方などの医学的判断の代わりになるものではありません。
- 生成AIは、もっともらしい誤り（いわゆるハルシネーション）を出力することがあります。出力内容は、必ず医師などの資格を持つ専門職が、最新のエビデンスや診療ガイドライン、添付文書などと照らし合わせて検証してください。
- 出力内容を診療に用いるかどうかの最終的な判断と責任は、利用者ご自身にあります。

### 2. 患者情報を入力しないでください

- 患者の氏名、ID、生年月日、住所など、個人を特定できる情報は入力しないでください。病歴などの要配慮個人情報も同様です。
- 症例を扱う場合は、個人が特定されないよう十分に匿名化・加工したうえで使用してください。
- 生成AIサービスの利用にあたっては、個人情報保護法や「医療情報システムの安全管理に関するガイドライン」（厚生労働省）などの関係法令・ガイドラインを守ってください。あわせて、所属医療機関の規程に従ってください。
- 利用するAIサービスの利用規約やプライバシーポリシーも確認してください。特に、入力したデータがAIの学習に利用されるかどうか、またその設定方法を確認することをおすすめします。

### 3. 出力は変わることがあります

- 同じプロンプトでも、使用するAIサービスやモデルの種類・バージョン、設定によって出力は異なります。
- モデルの更新によって、書籍の出力例とは異なる結果になる場合があります。
